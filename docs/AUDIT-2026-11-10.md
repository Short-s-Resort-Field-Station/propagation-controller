# System Audit — Propagation Unit 01 — 2026-11-10

Scope: the whole unit as it stands after first hardware bring-up (2026-11-09/10):
the Go daemon (`propagationd`), watchdog, both UIs, the Piconium OS/service
deployment, and the as-built hardware record. Findings are ranked; each has a
concrete scenario on this hardware and a fix. Sections 2 and 3 were produced by
two independent code reviewers reading the actual code paths; section 1 is the
deployed box, inspected live over SSH.

Severity: **CRIT** can energize or strand a load, or lock the unit without a
human noticing · **HIGH** wrong behaviour the grower will hit · **MED** robustness
/ correctness · **LOW** hygiene.

## 2. Backend (Go) — reviewer findings

Reviewed all of `internal/` and `cmd/` against HANDOFF, SPEC §9/§12 and AS-BUILT. `go build`, `go vet`, `go test ./...` clean. Note the Numato board is jumpered to **external 12 V** (F6), so its relays **hold their last state** if USB or the daemon disappears — that is what makes F2 and F5 matter.

| # | Sev | Finding | Scenario on this hardware | Fix |
| --- | --- | --- | --- | --- |
| 2.1 (F1) | **CRIT** | **Drain is refused exactly when it is needed.** `Enqueue` (`engine.go` ~248) runs `safety.Authorize(PumpChannel, On)` for every request, including `DrainOnly`; any lockout fails it. Introduced today; the test passes only because the fixture seeds the reservoir at 80 %. | Box 2 power blip ⇒ transmitter reverts ⇒ `reservoir_sensor_offline` ⇒ interrupted cycle says "use Drain" ⇒ Drain returns 409 "pump is locked out". Tray stays full. Same for `reservoir_low`. | Skip pump authorization when `DrainOnly`; the valve path still honours e-stop via `relayOnChecked`. |
| 2.2 (F2) | **HIGH** | **Relay board unreachable ⇒ nobody can turn the pump off, and the watchdog calls the daemon healthy.** Watchdog health only needs HTTP 200 + `database=ok`; the supervisor returns silently when its relay snapshot fails; the Numato driver has no reopen path (opened once in `Manager.Start`); `relayOff` and the backstop timers try once. | USB hiccup or a bench script holding `/dev/ttyACM0` mid-flood: pump stays on (relays hold state on external 12 V) until something re-opens the port. Only the 31-min max-runtime path retries, and only once a lockout exists. | (a) watchdog: `relay_controller` not online for N checks ⇒ unhealthy ⇒ restart ⇒ seize + force-off; (b) driver/manager reopen with backoff on I/O error; (c) supervisor logs `relay_controller_unreachable` and on recovery re-forces pump off unless the engine reports an active flood. |
| 2.3 (F3) | **HIGH** | **E-stop latch and the manual pump-max-runtime lockout are memory-only** (`supervisor.go` 142-192 loads only config). | Operator hits E-STOP; a deploy/watchdog restart/power blip restarts the daemon; lighting restore re-energizes lights and automation (when re-enabled) waters, with no Reset ever performed. Spec §12.3 says latched until manual reset. | Persist `{estop, manual lockouts}` under a settings key; reload in `Supervisor.Start`; re-force safe state on load. |
| 2.4 (F4) | **HIGH** | **Manual relay commands can dead-head the pump or fight a running cycle.** `/relays/7/set on` accepts `timeout_seconds: 0` (pump against a closed manifold, only the 1860 s backstop ends it); a valve `off` (or `on` with a short timeout, which *replaces* the engine's backstop timer) during a flood closes the valve while the engine keeps pumping; `flood()` never re-reads valve/pump state. | A remote Grower, or a bench script like today's, during a cycle. | Refuse pump-on without a timeout (cap ~60 s); refuse pump/valve commands while a cycle is active; `flood()` aborts if the valve or pump reads off. |
| 2.5 (F5) | **MED** | **Safe-state channel lists don't match the as-built map.** Watchdog forces 2–7 (misses **channel 1 = Shelf 1 valve**, comment is from the old map); manager `safeOffChannels` = {1,2,3,5,7} skips fans (4) and spare (6); spec §12.2 says spares off. | A crash with Shelf 1's valve open: the watchdog's force-off leaves it open (pump off, so water sits). A fan left on by a crash has no timer. | One exported `SafeOffChannels` = {1..7} used by both. |
| 2.6 (F6) | **MED** | **E-stop / all-off leave the engine "draining" for 300 s with the valve already closed** (today's abort-drain waits on `rootCtx`; e-stop and all-off have already closed the valve). | UI says "draining", nothing drains, zone rejects Enqueue for 5 min, queue blocked. Nothing energized; state dishonest; no "use Drain" hint. | E-stop calls `engine.StopAll` via callback; abort-drain checks `Authorize(valveCh, On)` before waiting and, if refused, closes and logs "tray may hold water — use Drain". |
| 2.7 (F7) | **MED** | **Drain inputs unvalidated.** `drain_seconds` PATCH accepts anything (negative ⇒ valve backstop ≤ 0 ⇒ *no* valve timer); `/drain` `duration_seconds` bypasses the max check (999999 ⇒ valve open 11 days, all watering blocked). | Admin-only, but silent. | Validate `0 ≤ drain_seconds ≤ 3600`; cap drain-only duration. |
| 2.8 (F8) | **MED** | **A Modbus scan can abort a running flood**: the bus mutex is held for the whole range (6–49 s), pollers queue, the reservoir reading goes stale (60 s window) ⇒ `reservoir_sensor_offline` ⇒ flood aborts. Operator-level endpoint. | Someone runs the diagnostics scan during a soak. | Refuse scans while a cycle is active, or lock per address. |
| 2.9 (F11) | **MED** | **`automation` settings key stored raw; `Enabled()` returns true on any parse failure or missing field.** | A typo'd PUT (`{"enabled":"false"}`) silently re-enables automation while the unit is parked. | Validate like `maintenance`; malformed ⇒ disabled. |
| 2.10 (F12) | **MED** | **Schedule catch-up on a forward clock jump**: `lastCheck` is set at Start, before NTP sync on a box with a lagging RTC; the first tick after sync walks every missed minute and fires each schedule once. | Unexpected watering minutes after a cold boot once schedules exist. | Cap the catch-up window to 2× interval; larger gaps = missed, skip (§11.2). |
| 2.11 (F16) | **MED** | **Lighting override is memory-only.** | Current state (schedule disabled, lights on by override): a power loss brings the Numato up all-off and the daemon applies nothing ⇒ lights dark until a human. | Persist `{mode, until}`; re-apply in `Start`. |
| 2.12 (F17) | **MED** | **Auto-recommission preconditions** for the level transmitter: `modbus.Bus` has no write method and the RTU baud is fixed at open. Also: with the placeholder depth the bucket reads ~20 % vs a 20 % minimum, so `reservoir_low` flaps on poll jitter. | — | Add `WriteRegister` + a `WithBaud` section to `RTUBus`; pause pollers; fc06 reg0=6 at addr 1 @ 9600, then reg1=2 at addr 6; reopen at 4800. Consider moving soil probe 1 off address 1 so "something at 1 @ 9600" is unambiguously a reverted transmitter. |
| 2.13 | **LOW** | F9 pump runtime accumulates across back-to-back cycles when `drain_seconds=0` (1 Hz sampling misses the ~100 ms gap) ⇒ three 30-min soaks trip the 1860 s backstop. F10 supervisor swallows DB read errors (lockout state freezes). F13 retention cutoff not hour-aligned ⇒ one partial bucket/day overwritten. F14 Stop during a normal drain records `complete`. F15 no embedded tzdata ⇒ silent UTC fallback for the photoperiod if zoneinfo is missing. F18 `/drain` is admin-only while `/run`/`/stop` are operator. F19 `http.Server` has no header/idle timeouts; anonymous SSE unbounded; `Shutdown` always waits the full 10 s. F20 legacy `static/touch.html` still says fans = 7 (unused). | — | Engine reports pump-stop to the supervisor; log + lockout on persistent DB errors; `cutoff.Truncate(time.Hour)`; record `aborted`; `import _ "time/tzdata"`; add `/drain` to operator list; server timeouts + SSE cap; delete the legacy shell. |

Sound: `Authorize` gates every on-path and never blocks off; e-stop re-forced every tick; lockout/engine race ≤ 1 s and the flood loop re-checks every 250 ms; backstop arithmetic (zone cap 1800 < pump timer ≤ 1815 < supervisor 1860); FIFO one-shelf invariant incl. drain; valve-before-pump / pump-before-valve on every path; `relayOff` on a background ctx so cancellation can't skip it; goroutine lifecycles exit on ctx; modernc time round-trip verified (all writers `.UTC()`, lexicographic compare holds); migrations versioned/idempotent; `AbortInterrupted` before the worker; auth: all mutations gated, XFF only demotes, tokens hashed, SameSite=Lax, last-admin guard.
